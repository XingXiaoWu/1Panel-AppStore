## 产品介绍

**WaibibabuClash** 是一款自托管的 Mihomo 多实例管理面板，提供实例管理、运行总览、代理组、活动连接、规则、YAML 配置和 REST API 控制台。本安装包使用官方发布的 Docker 镜像，仅支持 Linux ARM64 主机。

## 主要功能

- **多实例管理**：每个实例独立启动、停止和重启，拥有独立的代理端口与控制器端口，可在规则、全局、直连三种模式间切换。
- **订阅与配置**：维护全局共享的完整配置和节点订阅目录，订阅可被多个实例关联；支持 YAML 高级编辑与 IPv6、DNS 可视化设置。
- **容器间代理**：同一 `1panel-network` 内的其他容器可通过 `waibibabuclash:<实例代理端口>` 使用代理。实例需开启 `allow-lan` 并监听 `0.0.0.0` 或 `*`；代理端口不映射到宿主机。
- **管理面板**：面板没有登录认证，默认仅绑定宿主机 `127.0.0.1`。如需从外部访问，请通过带认证的 HTTPS 反向代理，或在确认访问控制后调整绑定地址。
- **数据持久化**：实例、订阅、配置和提取的代理内核保存在应用持久化目录的 `WaibibabuClash` 子目录中。

管理面板容器端口为 `8080`，宿主机端口由安装时的 Web UI 端口参数指定。代理端口由 Mihomo 实例配置决定，安装包不会自动开放或映射它们。
