## 产品介绍

**WaibibabuClash** 是一款自托管的 Mihomo 代理实例管理面板，支持管理多个实例、订阅和配置。此安装包仅适用于 Linux ARM64，内含离线 Docker 镜像。

## 主要功能

- **容器间代理**：同一 `1panel-network` 内的其他容器可通过 `waibibabuclash:<实例代理端口>` 使用代理。实例需开启 `allow-lan` 并监听 `0.0.0.0` 或 `*`；代理端口不映射到宿主机。
- **管理面板**：面板没有登录认证，默认仅绑定宿主机 `127.0.0.1`。如需从外部访问，请通过带认证的 HTTPS 反向代理，或在确认访问控制后调整绑定地址。
- **数据持久化**：实例、订阅、配置和提取的代理内核保存在应用持久化目录。

管理面板容器端口为 `8080`。代理端口由 Mihomo 实例配置决定，安装包不会自动开放或映射它们。
