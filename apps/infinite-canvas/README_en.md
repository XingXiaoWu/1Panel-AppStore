## Introduction

**Infinite Canvas** is an open-source visual workspace that combines canvas composition, AI image generation, reference editing, an assistant, prompt libraries, and asset management.

## Features

- **Infinite Canvas**: Create projects with draggable and resizable nodes, connections, minimap, undo/redo, and import/export.
- **AI Creation**: Call OpenAI-compatible endpoints directly from the browser for image, text, audio, and video generation.
- **Local Assets**: Canvas projects, generation history, and assets are stored in the browser with optional WebDAV sync.
