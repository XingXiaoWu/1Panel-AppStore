## Introduction

**ACP-Ant** is a self-hosted gateway that turns Google's official Antigravity CLI into standard LLM APIs over ACP.

## Features

- **Multiple API formats**: Provides OpenAI Chat Completions, Responses and Anthropic Messages with streaming and tool calling.
- **Multiple accounts and proxies**: Supports separate Google accounts and proxies, routing requests across available accounts.
- **Web control panel**: Manage accounts, proxies, quotas, keys and service status from a web panel.
